# Plotar Com Python 📊

Repositório criado a partir de códigos iniciais passados em aula utilizando **Pandas** e **Matplotlib** para a geração e visualização de gráficos de gastos. O objetivo principal deste projeto é evoluir e refatorar os scripts originais, aplicando boas práticas de programação.

---

## 🚀 Sobre o Projeto

Os códigos iniciais fornecidos pelo professor realizavam a plotagem direta de dados financeiros (orçado vs. realizado e gastos diários da semana). Este repositório tem como propósito:

* **Modularização:** Organizar o código em funções específicas para cada ação, facilitando a manutenção e a reutilização.
* **Evolução Futura:** Implementar uma interface gráfica interativa utilizando **PySide6**.

---

## 🛠️ Tecnologias Utilizadas

* **Python**
* **Pandas** (Manipulação e estruturação de dados)
* **Matplotlib** (Visualização e criação de gráficos)
* **PySide6** *(Planejado para o futuro)*

---

## 📂 Estrutura do Repositório

O projeto conta com scripts voltados para a análise visual de dados de despesas, divididos inicialmente entre categorias de gastos mensais e acompanhamento diário.
